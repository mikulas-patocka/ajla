How to uninstall Ajla

If you have Windows with Cygwin, please perform both the Cygwin with Windows and Windows outside Cygwin headings.

Cygwin in Windows and other systems than Windows or OS/2

  1. Run `which ajla` . If it prints where the executable is, delete it.
  2. Search for all files named ajla in the following directories, and delete all copies found: You may use this command to find them: 
    find /bin /sbin /usr/bin /usr/sbin /usr/local/bin /opt/bin ~/bin ~/.local/bin /data/data/com.termux/files/usr/bin -maxdepth 1 -type f -name ajla 2>/dev/null
  3. Search for all subdirectories named ajla-* in the following directories, and delete all of them. You may use this command to list them: 
    find /lib /usr/lib /usr/local/lib /opt/lib ~/lib ~/.local/lib /data/data/com.termux/files/usr/lib -maxdepth 1 -type d -iname 'ajla-*' 2>/dev/null
  4. echo $PATH and look for all Ajla-related paths. Use them as a hint to delete the ajla file and ajla-* directory which is inside a directory where you have to replace /bin in the path with /lib.
  5. Edit ~/.profile and remove all those Ajla-related paths from the PATH= variable.
  6. If you removed any PATH= entries from ~/.profile, try these actions one by one until the Ajla-related paths disappear from echo $PATH :
    1. Log out from all consoles, terminal emulators (xterm,...), and SSH's and log in again
    2. Reboot the system

OS/2

  1. Remove the C:\AJLA directory.
  2. Edit C:\CONFIG.SYS and remove C:\AJLA and separating semicolon from the SET PATH line (don't leave double semicolon ;;).
  3. Reboot.

(64-bit Windows Vista or 7) outside Cygwin

  1. Remove the C:\Ajla and C:\Program Files\Ajla directories if they exist.
  2. Start Menu, right click Computer, select Properties, Advanced System Settings in the left column. In the System Properties window, click the Advanced tab, then the Environment Variables button. Highglight the Path variable in the System Variables section and click Edit. There will be a list of paths separated by a semicolon. Remove all Ajla-related ones and their separating semicolons (don't leave double semicolons ;;). Click as many OK buttons as it takes. If you did any change, restart the computer.

(64-bit Windows 8, 10 or 11) outside Cygwin

  1. Remove the C:\Ajla and C:\Program Files\Ajla directories if they exist.
  2. Hold the [Windows logo] key and press X to show the Power User Task Menu. Select System; Advanced System Settings. In the System Properties window, select the Advanced tab, then click the Environment Variables button. Go to the System Variables section, find “Path”, click “Edit” and remove all Ajla-related entries and their separating semicolons (don't leave double semicolons ;;). Click as many OK buttons as it takes. If you did any change, close all open command shells.
